LoGoNet 模块文档（算子级重构版）¶

本网站展示了基于 算子（operator）方式重构的 LoGoNet 跨模态融合模块。
该重构将原始 LoGoNet 网络拆解为 可复用、可替换、可组合的融合算子与网络层， 以便于结构理解、模块复现与后续扩展研究。

当前文档主要包括以下四个核心阶段及整体框架说明：

  • Global Fusion（全局融合）
    在场景层面将点云特征与图像特征进行对齐与融合，增强点云的语义表达能力。

  • Local Fusion（局部融合）
    在候选框（RoI）内部进行细粒度跨模态融合，引入目标内部结构与局部语义信息。

  • Feature Aggregation（特征聚合）
    对多源融合特征进行关系建模与动态聚合，统一整合全局、局部与几何先验信息。

  • LoGoNet 融合框架（Framework）
    以算子化方式组织整体融合流程，定义统一接口并串联各阶段模块。

所有算子与网络模块的文档均通过 mkdocstrings
从对应 Python 代码的 docstring 注释中自动生成，确保文档与实现的一致性。
