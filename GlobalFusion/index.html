Global Fusion（全局融合）¶

本阶段的作用是 在场景层面将点云特征与图像特征进行对齐与融合， 通过引入图像语义信息增强点云特征的表达能力，为后续基于候选框的局部建模提供更具判别力的输入。

全局融合阶段不关注单个目标的内部结构，而是从整体角度完成跨模态信息注入， 属于 LoGoNet 融合流程中的 第一层跨模态融合。

本阶段包含四个算子：

  1. compute_voxel_centroid
    计算每个 voxel 内部点云的几何质心，用于代表该 voxel 的空间位置。

  2. project_points_to_image
    将 voxel 质心从三维空间投影到二维图像平面，建立点云与图像之间的空间对应关系。

  3. GlobalFusionLayer
    在全局尺度下从图像特征图采样与 voxel 对应的语义信息，并注入到点云特征中，输出语义增强后的点云表示。

  4. roi_feature_pooling
    根据 3D 候选框（RoI）对融合后的点云特征进行汇聚，生成候选框级特征表示。

def compute_voxel_centroid(
        voxel_points: torch.Tensor,
        voxel_num_points: torch.Tensor
) -> torch.Tensor:
    """
    计算每个 voxel 内点云的质心（centroid），作为该 voxel 的几何代表点。

    Args:
        voxel_points: (M, T, 3)
            每个 voxel 内的点云坐标，
            M 表示 voxel 数量，
            T 表示每个 voxel 的最大点数，
            3 表示点的三维坐标 (x, y, z)。

        voxel_num_points: (M,)
            每个 voxel 内的有效点数量。

    Returns:
        centroids: (M, 3)
            voxel 级点云质心坐标，
            第 i 行表示第 i 个 voxel 内所有点的平均空间位置。
    """
    # 对 voxel 内所有点坐标求和
    points_sum = voxel_points.sum(dim=1)

    # 防止除以 0，保证数值稳定
    normalizer = torch.clamp_min(
        voxel_num_points.view(-1, 1).to(voxel_points.dtype),
        min=1.0
    )

    # 计算 voxel 内点云质心
    centroids = points_sum / normalizer

    return centroids

@torch.library.custom_op(
    "logonet::project_points_to_image",
    mutates_args=[]
)
def project_points_to_image(
        points_3d: torch.Tensor,
        intrinsic: torch.Tensor,
        extrinsic: torch.Tensor
) -> torch.Tensor:
    """
    将三维空间中的点投影到图像平面，得到对应的二维像素坐标。

    Args:
        points_3d: (N, 3)
            三维点坐标，格式为 (x, y, z)。

        intrinsic: (3, 3)
            相机内参矩阵。

        extrinsic: (4, 4)
            相机外参矩阵，从 LiDAR 坐标系到相机坐标系的变换。

    Returns:
        points_2d: (N, 2)
            投影后的二维像素坐标，格式为 (u, v)。
    """
    # 齐次坐标扩展
    ones = torch.ones(
        (points_3d.shape[0], 1),
        device=points_3d.device,
        dtype=points_3d.dtype
    )
    points_homo = torch.cat([points_3d, ones], dim=1)  # (N, 4)

    # 从 LiDAR 坐标系变换到相机坐标系
    points_cam = (extrinsic @ points_homo.t()).t()[:, :3]  # (N, 3)

    # 过滤深度为 0 或负值的点，避免非法投影
    z = torch.clamp_min(points_cam[:, 2], min=1e-5)

    # 应用相机内参进行投影
    uv = (intrinsic @ points_cam.t()).t()  # (N, 3)

    u = uv[:, 0] / z
    v = uv[:, 1] / z

    points_2d = torch.stack([u, v], dim=1)
    return points_2d

GlobalFusionLayer¶

GlobalFusionLayer ¶

Bases: Module

GlobalFusionLayer 模块（LoGoNet 全局融合阶段核心算子）。

该模块在场景级别对点云特征与图像特征进行跨模态融合，用于为 voxel / proposal 引入来自图像的语义信息。其核心思想是：以点云特征为引导，在图像特征图中 动态采样与其空间位置对应的图像特征，并完成跨模态特征对齐与融合。

本模块属于 可学习算子，其内部包含线性映射与注意力权重相关参数， 在训练过程中通过反向传播进行更新。

结构说明（按顺序）¶
  1. Linear：点云特征 → Query
  2. 将点云特征映射到查询空间。
  3. Linear：点云特征 → Offset / Weight
  4. 预测图像特征的采样偏移与融合权重。
  5. 图像特征采样
  6. 在图像特征图中，根据投影位置与偏移进行局部采样。
  7. 特征融合
  8. 将采样到的图像特征与点云特征进行加权融合，输出增强后的点云特征。
输入¶

Args: lidar_feat (torch.Tensor): 点云特征张量，shape 为 (N, C_l)， N 表示 voxel / 点数量，C_l 表示点云特征维度。

image_feat (torch.Tensor):
    图像特征张量，shape 为 **(B, C_i, H, W)**，
    B 为 batch size，C_i 为图像特征通道数。

proj_points (torch.Tensor):
    点云特征对应的图像投影坐标，shape 为 **(N, 2)**，
    表示每个点在图像平面上的 (u, v) 位置。
输出¶

Returns: torch.Tensor: 融合后的点云特征，shape 为 (N, C_l)， 每个点云特征已注入对应的图像语义信息。

模块用途¶
  • 在全局尺度下完成点云与图像的跨模态特征融合
  • 为后续 proposal 级与局部融合提供语义增强的点云表示
  • 属于 LoGoNet 的 GlobalFusion（GoF）阶段核心算子

class GlobalFusionLayer(nn.Module):
    """
    GlobalFusionLayer 模块（LoGoNet 全局融合阶段核心算子）。

    该模块在场景级别对点云特征与图像特征进行跨模态融合，用于为 voxel / proposal
    引入来自图像的语义信息。其核心思想是：以点云特征为引导，在图像特征图中
    动态采样与其空间位置对应的图像特征，并完成跨模态特征对齐与融合。

    本模块属于 **可学习算子**，其内部包含线性映射与注意力权重相关参数，
    在训练过程中通过反向传播进行更新。

    ---
    ### 结构说明（按顺序）
    1. **Linear：点云特征 → Query**
       - 将点云特征映射到查询空间。
    2. **Linear：点云特征 → Offset / Weight**
       - 预测图像特征的采样偏移与融合权重。
    3. **图像特征采样**
       - 在图像特征图中，根据投影位置与偏移进行局部采样。
    4. **特征融合**
       - 将采样到的图像特征与点云特征进行加权融合，输出增强后的点云特征。

    ---
    ### 输入
    Args:
        lidar_feat (torch.Tensor):
            点云特征张量，shape 为 **(N, C_l)**，
            N 表示 voxel / 点数量，C_l 表示点云特征维度。

        image_feat (torch.Tensor):
            图像特征张量，shape 为 **(B, C_i, H, W)**，
            B 为 batch size，C_i 为图像特征通道数。

        proj_points (torch.Tensor):
            点云特征对应的图像投影坐标，shape 为 **(N, 2)**，
            表示每个点在图像平面上的 (u, v) 位置。

    ---
    ### 输出
    Returns:
        torch.Tensor:
            融合后的点云特征，shape 为 **(N, C_l)**，
            每个点云特征已注入对应的图像语义信息。

    ---
    ### 模块用途
    - 在全局尺度下完成点云与图像的跨模态特征融合
    - 为后续 proposal 级与局部融合提供语义增强的点云表示
    - 属于 LoGoNet 的 GlobalFusion（GoF）阶段核心算子
    """

    def __init__(self, lidar_channels: int, image_channels: int):
        super().__init__()
        self.query_fc = nn.Linear(lidar_channels, lidar_channels)
        self.value_fc = nn.Linear(image_channels, lidar_channels)

    def forward(
        self,
        lidar_feat: torch.Tensor,
        image_feat: torch.Tensor,
        proj_points: torch.Tensor
    ) -> torch.Tensor:
        """
        前向传播过程。
        """
        # 点云特征映射到查询空间
        query = self.query_fc(lidar_feat)  # (N, C_l)

        # 将投影坐标归一化到 [-1, 1]，用于 grid_sample
        h, w = image_feat.shape[-2:]
        norm_u = proj_points[:, 0] / (w - 1) * 2 - 1
        norm_v = proj_points[:, 1] / (h - 1) * 2 - 1
        grid = torch.stack([norm_u, norm_v], dim=1).view(1, -1, 1, 2)

        # 从图像特征中采样对应位置的特征
        sampled_feat = torch.nn.functional.grid_sample(
            image_feat,
            grid,
            align_corners=True
        ).view(image_feat.shape[1], -1).t()  # (N, C_i)

        # 图像特征映射到点云特征空间
        image_emb = self.value_fc(sampled_feat)

        # 跨模态特征融合
        fused_feat = query + image_emb

        return fused_feat

@torch.library.custom_op(
    "logonet::roi_feature_pooling",
    mutates_args=[]
)
def roi_feature_pooling(
        voxel_features: torch.Tensor,
        voxel_coords: torch.Tensor,
        rois: torch.Tensor
) -> torch.Tensor:
    """
    根据 3D 候选框（RoI）对点云特征进行汇聚，生成候选框级特征表示。

    该算子将已经完成全局融合的 voxel 特征，按照每个 3D 框的空间范围进行筛选与聚合，
    从而得到每个候选框对应的整体特征表示。本算子仅执行几何索引与特征聚合操作，
    不包含可学习参数。

    Args:
        voxel_features: (M, C)
            voxel 级特征张量，M 为 voxel 数量，C 为特征维度。

        voxel_coords: (M, 3)
            voxel 对应的三维坐标 (x, y, z)。

        rois: (K, 7)
            3D 候选框参数，格式为 (x, y, z, dx, dy, dz, yaw)。

    Returns:
        roi_features: (K, C)
            每个 3D 候选框对应的聚合特征，
            第 i 行表示第 i 个候选框的整体点云特征。
    """
    K = rois.shape[0]
    C = voxel_features.shape[1]

    roi_features = voxel_features.new_zeros((K, C))

    for i in range(K):
        cx, cy, cz, dx, dy, dz, _ = rois[i]

        # 判断 voxel 是否落在当前 RoI 内
        mask = (
            (voxel_coords[:, 0] >= cx - dx / 2) &
            (voxel_coords[:, 0] <= cx + dx / 2) &
            (voxel_coords[:, 1] >= cy - dy / 2) &
            (voxel_coords[:, 1] <= cy + dy / 2) &
            (voxel_coords[:, 2] >= cz - dz / 2) &
            (voxel_coords[:, 2] <= cz + dz / 2)
        )

        if mask.any():
            # 对 RoI 内 voxel 特征进行平均聚合
            roi_features[i] = voxel_features[mask].mean(dim=0)

    return roi_features
