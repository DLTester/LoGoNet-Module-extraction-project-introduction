Feature Aggregation（特征聚合）¶

本阶段的作用是 对来自不同融合路径的多源特征进行统一整合与关系建模， 通过在候选框（RoI）内部对局部网格特征进行动态聚合， 增强模型对目标整体结构与语义一致性的建模能力。

特征聚合阶段承接全局融合与局部融合的输出， 属于 LoGoNet 融合流程中的 最终特征建模阶段， 其输出将直接用于后续的候选框分类与位置回归。

本阶段包含三个算子：

  1. merge_fusion_features
    对全局融合特征、局部融合特征以及几何位置编码特征进行合并， 生成统一的网格级融合特征表示。

  2. FeatureAggregationLayer
    在候选框内部对网格级融合特征进行关系建模， 通过自注意力机制实现不同局部网格之间的信息交互与动态聚合。

  3. RoIRefineHead
    对聚合后的候选框级特征进行分类与三维框参数回归， 输出最终的检测置信度与精细化的位置预测结果。

merge_fusion_features¶

merge_fusion_features(global_feat, local_feat, pos_feat) ¶

融合多源特征（全局融合特征、局部融合特征与几何位置编码特征）。

该算子用于在特征聚合阶段（FDA）之前，对来自不同融合路径的特征进行 统一合并。融合方式采用逐元素相加，不引入额外的可学习参数， 仅完成特征对齐与信息汇总。

Parameters:

    (K, G, C) 全局融合得到的特征张量， K 为候选框数量， G 为网格数量， C 为特征维度。

  • local_feat (Tensor) –

    (K, G, C) 局部融合得到的特征张量。

  • pos_feat (Tensor) –

    (K, G, C) 几何位置编码特征张量。
Returns:
  • fused_feat( Tensor ) –

    (K, G, C) 合并后的融合特征张量，作为后续特征关系建模的输入。

@torch.library.custom_op(
    "logonet::merge_fusion_features",
    mutates_args=[]
)
def merge_fusion_features(
        global_feat: torch.Tensor,
        local_feat: torch.Tensor,
        pos_feat: torch.Tensor
) -> torch.Tensor:
    """
    融合多源特征（全局融合特征、局部融合特征与几何位置编码特征）。

    该算子用于在特征聚合阶段（FDA）之前，对来自不同融合路径的特征进行
    统一合并。融合方式采用逐元素相加，不引入额外的可学习参数，
    仅完成特征对齐与信息汇总。

    Args:
        global_feat: (K, G, C)
            全局融合得到的特征张量，
            K 为候选框数量，
            G 为网格数量，
            C 为特征维度。

        local_feat: (K, G, C)
            局部融合得到的特征张量。

        pos_feat: (K, G, C)
            几何位置编码特征张量。

    Returns:
        fused_feat: (K, G, C)
            合并后的融合特征张量，作为后续特征关系建模的输入。
    """
    fused_feat = global_feat + local_feat + pos_feat
    return fused_feat

FeatureAggregationLayer¶

FeatureAggregationLayer ¶

Bases: Module

FeatureAggregationLayer 模块（LoGoNet 特征动态聚合阶段核心算子）。

该模块用于在候选框（RoI）内部对网格级融合特征进行关系建模与动态聚合， 使不同局部网格之间能够进行信息交互，从而统一整合全局融合、局部融合与几何先验 所形成的多源特征表示。其本质是对网格序列特征进行自注意力建模，并通过前馈网络 进一步增强表达能力。

本模块属于 可学习算子，其参数在训练过程中根据监督信号更新。

结构说明（按顺序）¶
  1. MultiheadAttention（自注意力）
  2. 在同一候选框内部，让各网格特征互相关注，实现局部关系建模。
  3. 残差连接 + LayerNorm
  4. 稳定训练并保留原始特征信息。
  5. 前馈网络（FFN）
  6. 对每个网格特征做非线性变换，增强语义表达能力。
  7. 残差连接 + LayerNorm
  8. 输出聚合后的网格级融合特征。
输入¶

Args: fused_feat (torch.Tensor): 网格级融合特征，shape 为 (K, G, C)， K 为候选框数量，G 为每个候选框的网格数量，C 为特征维度。

attn_mask (torch.Tensor, optional):
    注意力掩码，shape 为 **(G, G)** 或可广播到该形状，用于屏蔽无效网格之间的注意力。
输出¶

Returns: torch.Tensor: 聚合后的网格级特征，shape 为 (K, G, C)。

模块用途¶
  • 在 RoI 内部建立网格之间的关系，提升对目标内部结构的表达能力
  • 统一整合多源融合信息，为最终框回归与置信度预测提供高质量特征
  • 属于 LoGoNet 的 Feature Dynamic Aggregation（FDA）阶段核心算子

class FeatureAggregationLayer(nn.Module):
    """
    FeatureAggregationLayer 模块（LoGoNet 特征动态聚合阶段核心算子）。

    该模块用于在候选框（RoI）内部对网格级融合特征进行关系建模与动态聚合，
    使不同局部网格之间能够进行信息交互，从而统一整合全局融合、局部融合与几何先验
    所形成的多源特征表示。其本质是对网格序列特征进行自注意力建模，并通过前馈网络
    进一步增强表达能力。

    本模块属于 **可学习算子**，其参数在训练过程中根据监督信号更新。

    ---
    ### 结构说明（按顺序）
    1. **MultiheadAttention（自注意力）**
       - 在同一候选框内部，让各网格特征互相关注，实现局部关系建模。
    2. **残差连接 + LayerNorm**
       - 稳定训练并保留原始特征信息。
    3. **前馈网络（FFN）**
       - 对每个网格特征做非线性变换，增强语义表达能力。
    4. **残差连接 + LayerNorm**
       - 输出聚合后的网格级融合特征。

    ---
    ### 输入
    Args:
        fused_feat (torch.Tensor):
            网格级融合特征，shape 为 **(K, G, C)**，
            K 为候选框数量，G 为每个候选框的网格数量，C 为特征维度。

        attn_mask (torch.Tensor, optional):
            注意力掩码，shape 为 **(G, G)** 或可广播到该形状，用于屏蔽无效网格之间的注意力。

    ---
    ### 输出
    Returns:
        torch.Tensor:
            聚合后的网格级特征，shape 为 **(K, G, C)**。

    ---
    ### 模块用途
    - 在 RoI 内部建立网格之间的关系，提升对目标内部结构的表达能力
    - 统一整合多源融合信息，为最终框回归与置信度预测提供高质量特征
    - 属于 LoGoNet 的 Feature Dynamic Aggregation（FDA）阶段核心算子
    """

    def __init__(self, channels: int, num_heads: int = 4, ffn_ratio: int = 4, dropout: float = 0.0):
        super().__init__()
        self.attn = nn.MultiheadAttention(
            embed_dim=channels,
            num_heads=num_heads,
            dropout=dropout,
            batch_first=True
        )
        self.norm1 = nn.LayerNorm(channels)

        hidden = channels * ffn_ratio
        self.ffn = nn.Sequential(
            nn.Linear(channels, hidden),
            nn.ReLU(),
            nn.Linear(hidden, channels),
        )
        self.norm2 = nn.LayerNorm(channels)

    def forward(
            self,
            fused_feat: torch.Tensor,
            attn_mask: Optional[torch.Tensor] = None
    ) -> torch.Tensor:
        """
        前向传播过程。
        """
        # 1) 自注意力建模（网格之间信息交互）
        attn_out, _ = self.attn(fused_feat, fused_feat, fused_feat, attn_mask=attn_mask, need_weights=False)
        x = self.norm1(fused_feat + attn_out)

        # 2) 前馈网络增强表达
        ffn_out = self.ffn(x)
        out = self.norm2(x + ffn_out)

        return out

RoIRefineHead¶

RoIRefineHead ¶

Bases: Module

RoIRefineHead 模块（LoGoNet 候选框回归与打分阶段算子）。

该模块基于经过特征动态聚合（FDA）后的网格级融合特征， 对每个候选框（RoI）进行最终的类别置信度预测与三维框参数回归。 其核心思想是：先将 RoI 内部的网格特征进行汇聚，形成候选框级表示， 再通过轻量级前馈网络分别完成分类与回归任务。

本模块属于 可学习算子，其参数在训练过程中根据检测监督信号更新。

结构说明（按顺序）¶
  1. 网格特征汇聚（Mean Pooling）
  2. 将 RoI 内部 G 个网格特征聚合为单一候选框特征。
  3. 共享全连接层
  4. 对候选框级特征进行非线性映射，形成高层语义表示。
  5. 分类分支（Classification Head）
  6. 输出每个候选框的类别置信度。
  7. 回归分支（Regression Head）
  8. 输出候选框的三维框回归参数。
输入¶

Args: roi_feat (torch.Tensor): RoI 内部聚合后的网格级特征，shape 为 (K, G, C)， K 为候选框数量，G 为每个候选框的网格数量，C 为特征维度。

输出¶

Returns: cls_score (torch.Tensor): 候选框分类得分，shape 为 (K, num_classes)。

reg_offset (torch.Tensor):
    候选框回归结果，shape 为 **(K, box_dim)**，
    box_dim 通常为 7，对应 (x, y, z, dx, dy, dz, yaw)。
模块用途¶
  • 对融合后的候选框进行最终分类与精细位置回归
  • 提升 3D 检测结果的定位精度与置信度可靠性
  • 属于 LoGoNet 检测头（Detection Head）的最后阶段

class RoIRefineHead(nn.Module):
    """
    RoIRefineHead 模块（LoGoNet 候选框回归与打分阶段算子）。

    该模块基于经过特征动态聚合（FDA）后的网格级融合特征，
    对每个候选框（RoI）进行最终的类别置信度预测与三维框参数回归。
    其核心思想是：先将 RoI 内部的网格特征进行汇聚，形成候选框级表示，
    再通过轻量级前馈网络分别完成分类与回归任务。

    本模块属于 **可学习算子**，其参数在训练过程中根据检测监督信号更新。

    ---
    ### 结构说明（按顺序）
    1. **网格特征汇聚（Mean Pooling）**
       - 将 RoI 内部 G 个网格特征聚合为单一候选框特征。
    2. **共享全连接层**
       - 对候选框级特征进行非线性映射，形成高层语义表示。
    3. **分类分支（Classification Head）**
       - 输出每个候选框的类别置信度。
    4. **回归分支（Regression Head）**
       - 输出候选框的三维框回归参数。

    ---
    ### 输入
    Args:
        roi_feat (torch.Tensor):
            RoI 内部聚合后的网格级特征，shape 为 **(K, G, C)**，
            K 为候选框数量，G 为每个候选框的网格数量，C 为特征维度。

    ---
    ### 输出
    Returns:
        cls_score (torch.Tensor):
            候选框分类得分，shape 为 **(K, num_classes)**。

        reg_offset (torch.Tensor):
            候选框回归结果，shape 为 **(K, box_dim)**，
            box_dim 通常为 7，对应 (x, y, z, dx, dy, dz, yaw)。

    ---
    ### 模块用途
    - 对融合后的候选框进行最终分类与精细位置回归
    - 提升 3D 检测结果的定位精度与置信度可靠性
    - 属于 LoGoNet 检测头（Detection Head）的最后阶段
    """

    def __init__(
        self,
        in_channels: int,
        num_classes: int = 1,
        box_dim: int = 7
    ):
        super().__init__()

        self.shared_fc = nn.Sequential(
            nn.Linear(in_channels, in_channels),
            nn.ReLU(),
            nn.Linear(in_channels, in_channels),
            nn.ReLU(),
        )

        self.cls_head = nn.Linear(in_channels, num_classes)
        self.reg_head = nn.Linear(in_channels, box_dim)

    def forward(self, roi_feat: torch.Tensor):
        """
        前向传播过程。
        """
        # 1) 网格维度聚合（Mean Pooling）
        pooled_feat = roi_feat.mean(dim=1)  # (K, C)

        # 2) 共享特征变换
        feat = self.shared_fc(pooled_feat)

        # 3) 分类与回归预测
        cls_score = self.cls_head(feat)
        reg_offset = self.reg_head(feat)

        return cls_score, reg_offset
