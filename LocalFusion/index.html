Local Fusion（局部融合）¶

本阶段的作用是 在候选框（RoI）内部进行细粒度跨模态融合， 通过将目标内部的局部点云结构与对应的图像局部语义进行对齐， 增强模型对目标内部空间结构与语义细节的建模能力。

与全局融合不同，局部融合关注的是 单个目标内部的局部区域， 属于 LoGoNet 融合流程中的 第二层跨模态融合。

本阶段包含四个算子：

  1. generate_roi_grids
    在每个 3D 候选框内部按照规则划分生成多个局部网格，用于刻画目标内部的空间结构。

  2. PositionEncodingLayer
    对 RoI 内部各网格的几何位置与统计信息进行编码，生成可学习的几何位置特征。

  3. project_grid_centers_to_image
    将 RoI 内部网格中心点从三维空间投影到二维图像平面，建立局部网格与图像区域之间的对应关系。

  4. LocalFusionLayer
    在网格级别对点云特征与图像特征进行跨模态融合，生成包含局部语义与几何信息的融合特征表示。

generate_roi_grids¶

generate_roi_grids(rois, grid_size) ¶

@torch.library.custom_op(
    "logonet::generate_roi_grids",
    mutates_args=[]
)
def generate_roi_grids(
        rois: torch.Tensor,
        grid_size: int
) -> torch.Tensor:
    """
    在每个 3D 候选框（RoI）内部生成规则的局部网格，用于后续局部特征建模。

    该算子将每个 3D 框在自身坐标系下均匀划分为若干个小立方体网格，
    并输出每个网格中心点的三维坐标。该过程仅依赖几何规则，
    不包含任何可学习参数。

    Args:
        rois: (K, 7)
            3D 候选框参数，格式为 (x, y, z, dx, dy, dz, yaw)，
            K 表示候选框数量。

        grid_size: int
            每个维度上的网格划分数量，
            总网格数为 grid_size³。

    Returns:
        grid_centers: (K, G, 3)
            每个候选框内部的网格中心点坐标，
            其中 G = grid_size³，
            第 i 个候选框对应 G 个局部网格中心。
    """
    K = rois.shape[0]
    G = grid_size ** 3

    device = rois.device
    dtype = rois.dtype

    # 生成归一化网格坐标 [0, 1]
    lin = torch.linspace(0.0, 1.0, grid_size, device=device, dtype=dtype)
    gx, gy, gz = torch.meshgrid(lin, lin, lin, indexing='ij')
    grid = torch.stack([gx, gy, gz], dim=-1).view(-1, 3)  # (G, 3)

    grid_centers = rois.new_zeros((K, G, 3))

    for i in range(K):
        cx, cy, cz, dx, dy, dz, _ = rois[i]

        # 将归一化网格映射到当前 RoI 的实际空间范围
        centers = grid.clone()
        centers[:, 0] = cx - dx / 2 + centers[:, 0] * dx
        centers[:, 1] = cy - dy / 2 + centers[:, 1] * dy
        centers[:, 2] = cz - dz / 2 + centers[:, 2] * dz

        grid_centers[i] = centers

    return grid_centers

PositionEncodingLayer ¶

Bases: Module

PositionEncodingLayer 模块（LoGoNet 局部融合阶段的几何位置编码算子）。

该模块用于对候选框（RoI）内部的局部网格进行几何信息编码， 将每个网格的相对空间位置以及点云分布密度信息映射到 可学习的特征空间中，从而为后续局部跨模态融合提供结构先验。

本模块属于 可学习算子，其参数通过训练自动学习， 但其输入仅依赖几何与统计信息，不涉及图像或语义特征。

结构说明（按顺序）¶
  1. 输入拼接
  2. 网格中心相对位置 (dx, dy, dz)
  3. 网格内点数量的对数值 log(N + 1)
  4. Linear → ReLU
  5. 初步映射几何与密度信息
  6. Linear → ReLU
  7. 提升几何特征表达能力
  8. Linear
  9. 输出位置编码特征
输入¶

Args: grid_centers (torch.Tensor): RoI 内部网格中心点坐标，shape 为 (K, G, 3)， K 为候选框数量，G 为每个候选框内的网格数。

roi_centers (torch.Tensor):
    候选框中心坐标，shape 为 **(K, 3)**。

grid_point_counts (torch.Tensor):
    每个网格内的点数量，shape 为 **(K, G)**。
输出¶

Returns: torch.Tensor: 网格级几何位置编码特征，shape 为 (K, G, C)， C 为位置编码特征维度。

模块用途¶
  • 为 RoI 内部局部网格提供结构与密度先验
  • 引导后续局部跨模态融合关注目标内部有效区域
  • 属于 LoGoNet 的 LocalFusion（LoF）阶段关键算子

class PositionEncodingLayer(nn.Module):
    """
    PositionEncodingLayer 模块（LoGoNet 局部融合阶段的几何位置编码算子）。

    该模块用于对候选框（RoI）内部的局部网格进行几何信息编码，
    将每个网格的**相对空间位置**以及**点云分布密度信息**映射到
    可学习的特征空间中，从而为后续局部跨模态融合提供结构先验。

    本模块属于 **可学习算子**，其参数通过训练自动学习，
    但其输入仅依赖几何与统计信息，不涉及图像或语义特征。

    ---
    ### 结构说明（按顺序）
    1. **输入拼接**
       - 网格中心相对位置 (dx, dy, dz)
       - 网格内点数量的对数值 log(N + 1)
    2. **Linear → ReLU**
       - 初步映射几何与密度信息
    3. **Linear → ReLU**
       - 提升几何特征表达能力
    4. **Linear**
       - 输出位置编码特征

    ---
    ### 输入
    Args:
        grid_centers (torch.Tensor):
            RoI 内部网格中心点坐标，shape 为 **(K, G, 3)**，
            K 为候选框数量，G 为每个候选框内的网格数。

        roi_centers (torch.Tensor):
            候选框中心坐标，shape 为 **(K, 3)**。

        grid_point_counts (torch.Tensor):
            每个网格内的点数量，shape 为 **(K, G)**。

    ---
    ### 输出
    Returns:
        torch.Tensor:
            网格级几何位置编码特征，shape 为 **(K, G, C)**，
            C 为位置编码特征维度。

    ---
    ### 模块用途
    - 为 RoI 内部局部网格提供结构与密度先验
    - 引导后续局部跨模态融合关注目标内部有效区域
    - 属于 LoGoNet 的 LocalFusion（LoF）阶段关键算子
    """

    def __init__(self, out_channels: int):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(4, out_channels),
            nn.ReLU(),
            nn.Linear(out_channels, out_channels),
            nn.ReLU(),
            nn.Linear(out_channels, out_channels)
        )

    def forward(
        self,
        grid_centers: torch.Tensor,
        roi_centers: torch.Tensor,
        grid_point_counts: torch.Tensor
    ) -> torch.Tensor:
        """
        前向传播过程。
        """
        # 计算网格中心相对于 RoI 中心的偏移
        rel_pos = grid_centers - roi_centers.unsqueeze(1)  # (K, G, 3)

        # 对网格内点数量取对数，增强数值稳定性
        density = torch.log(grid_point_counts.float() + 1.0).unsqueeze(-1)  # (K, G, 1)

        # 拼接几何与密度信息
        pos_feat = torch.cat([rel_pos, density], dim=-1)  # (K, G, 4)

        # 几何位置编码
        encoded_feat = self.mlp(pos_feat)

        return encoded_feat

@torch.library.custom_op(
    "logonet::project_grid_centers_to_image",
    mutates_args=[]
)
def project_grid_centers_to_image(
        grid_centers: torch.Tensor,
        intrinsic: torch.Tensor,
        extrinsic: torch.Tensor
) -> torch.Tensor:
    """
    将 RoI 内部网格中心点从三维空间投影到图像平面，得到对应的二维像素坐标。

    该算子用于局部融合阶段（LoF），为每个候选框内部的局部网格
    提供与图像特征对齐的参考位置。本算子仅执行几何投影计算，
    不包含任何可学习参数。

    Args:
        grid_centers: (K, G, 3)
            RoI 内部网格中心点的三维坐标，
            K 为候选框数量，
            G 为每个候选框内的网格数量。

        intrinsic: (3, 3)
            相机内参矩阵。

        extrinsic: (4, 4)
            相机外参矩阵，从 LiDAR 坐标系到相机坐标系的变换。

    Returns:
        grid_points_2d: (K, G, 2)
            网格中心点在图像平面上的二维像素坐标 (u, v)。
    """
    K, G, _ = grid_centers.shape

    # 展平为二维点集
    points_3d = grid_centers.view(-1, 3)  # (K*G, 3)

    # 齐次坐标
    ones = torch.ones(
        (points_3d.shape[0], 1),
        device=points_3d.device,
        dtype=points_3d.dtype
    )
    points_homo = torch.cat([points_3d, ones], dim=1)  # (K*G, 4)

    # 变换到相机坐标系
    points_cam = (extrinsic @ points_homo.t()).t()[:, :3]  # (K*G, 3)

    # 防止深度为 0 或负值
    z = torch.clamp_min(points_cam[:, 2], min=1e-5)

    # 相机内参投影
    uv = (intrinsic @ points_cam.t()).t()  # (K*G, 3)
    u = uv[:, 0] / z
    v = uv[:, 1] / z

    grid_points_2d = torch.stack([u, v], dim=1).view(K, G, 2)

    return grid_points_2d

LocalFusionLayer¶

LocalFusionLayer ¶

Bases: Module

LocalFusionLayer 模块（LoGoNet 局部融合阶段核心算子）。

该模块在候选框（RoI）内部的局部网格尺度上，将点云局部特征与图像特征进行对齐与融合， 用于补充目标内部的细粒度语义信息。其基本过程是：对每个 RoI 的每个网格中心点进行图像投影， 从图像特征图中采样对应位置的局部语义特征，并与网格的几何位置编码特征共同融合，输出网格级融合特征。

本模块属于 可学习算子，内部包含特征映射与融合参数，训练过程中可通过监督信号更新。

结构说明（按顺序）¶
  1. Linear：位置编码特征 → Query
  2. 将网格几何编码映射到融合空间，用于引导局部融合。
  3. 图像特征采样（grid_sample）
  4. 根据网格投影位置从图像特征图提取局部语义特征。
  5. Linear：图像特征 → Value
  6. 将采样到的图像特征映射到融合空间。
  7. 融合 MLP
  8. 将 Query 与 Value 拼接后进行非线性融合，输出网格级融合特征。
输入¶

Args: pos_feat (torch.Tensor): 网格几何位置编码特征，shape 为 (K, G, C_p)， K 为候选框数量，G 为每个候选框内的网格数量。

image_feat (torch.Tensor):
    图像特征张量，shape 为 **(B, C_i, H, W)**，
    B 为 batch size，C_i 为图像特征通道数。

grid_points_2d (torch.Tensor):
    网格中心点投影到图像平面的二维像素坐标，shape 为 **(K, G, 2)**，
    坐标格式为 (u, v)，以像素为单位。

batch_indices (torch.Tensor):
    每个 RoI 所属的 batch 索引，shape 为 **(K, )**。
输出¶

Returns: torch.Tensor: 网格级局部融合特征，shape 为 (K, G, C_out)。

模块用途¶
  • 在 RoI 内部对局部区域进行跨模态融合，增强目标内部结构表达
  • 为后续特征聚合与最终框回归、打分提供更细粒度的融合表示
  • 属于 LoGoNet 的 LocalFusion（LoF）阶段核心部分

            K 为候选框数量，G 为每个候选框内的网格数量。

            B 为 batch size，C_i 为图像特征通道数。

            网格中心点投影到图像平面的二维像素坐标，shape 为 **(K, G, 2)**，
            坐标格式为 (u, v)，以像素为单位。

        batch_indices (torch.Tensor):
            每个 RoI 所属的 batch 索引，shape 为 **(K, )**。

    ---
    ### 输出
    Returns:
        torch.Tensor:
            网格级局部融合特征，shape 为 **(K, G, C_out)**。

    ---
    ### 模块用途
    - 在 RoI 内部对局部区域进行跨模态融合，增强目标内部结构表达
    - 为后续特征聚合与最终框回归、打分提供更细粒度的融合表示
    - 属于 LoGoNet 的 LocalFusion（LoF）阶段核心部分
    """

    def __init__(self, pos_channels: int, image_channels: int, out_channels: int):
        super().__init__()
        self.query_fc = nn.Linear(pos_channels, out_channels)
        self.value_fc = nn.Linear(image_channels, out_channels)
        self.fuse_mlp = nn.Sequential(
            nn.Linear(out_channels * 2, out_channels),
            nn.ReLU(),
            nn.Linear(out_channels, out_channels),
        )

    def forward(
        self,
        pos_feat: torch.Tensor,
        image_feat: torch.Tensor,
        grid_points_2d: torch.Tensor,
        batch_indices: torch.Tensor
    ) -> torch.Tensor:
        """
        前向传播过程。
        """
        K, G, _ = pos_feat.shape
        _, C_i, H, W = image_feat.shape

        # 1) 位置编码 → Query
        query = self.query_fc(pos_feat)  # (K, G, C_out)

        # 2) 像素坐标归一化到 [-1, 1]，以支持 grid_sample
        u = grid_points_2d[..., 0]  # (K, G)
        v = grid_points_2d[..., 1]  # (K, G)
        norm_u = u / (W - 1) * 2 - 1
        norm_v = v / (H - 1) * 2 - 1
        grid = torch.stack([norm_u, norm_v], dim=-1)  # (K, G, 2)

        # 3) 按每个 RoI 的 batch 索引，从对应图像特征里采样
        sampled_list = []
        for i in range(K):
            b = int(batch_indices[i].item())
            grid_i = grid[i].view(1, G, 1, 2)  # (1, G, 1, 2)
            feat_i = image_feat[b:b + 1]       # (1, C_i, H, W)
            samp_i = F.grid_sample(feat_i, grid_i, align_corners=True)  # (1, C_i, G, 1)
            samp_i = samp_i.squeeze(0).squeeze(-1).transpose(0, 1)      # (G, C_i)
            sampled_list.append(samp_i)

        sampled_img = torch.stack(sampled_list, dim=0)  # (K, G, C_i)

        # 4) 图像特征 → Value
        value = self.value_fc(sampled_img)  # (K, G, C_out)

        # 5) 拼接后融合
        fused = self.fuse_mlp(torch.cat([query, value], dim=-1))  # (K, G, C_out)

        return fused
