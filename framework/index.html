Framework（融合框架总览）¶

本页面从整体角度介绍 LoGoNet 跨模态融合框架的算子级组织方式与执行流程。 该框架通过对原始网络进行算子化拆解，将复杂的融合过程拆分为 接口 → 算子 → 网络层 → 阶段模块 四个层次， 以提升结构可读性、模块复用性与实验可扩展性。

框架整体结构¶

LoGoNet 融合框架由以下三个核心阶段顺序组成：

  1. Global Fusion（全局融合）
    在场景层面将图像语义信息注入点云特征中，生成语义增强后的点云表示。

  2. Local Fusion（局部融合）
    在候选框（RoI）内部对目标结构进行细粒度跨模态融合，建模目标内部局部语义与几何关系。

  3. Feature Aggregation（特征聚合）
    对多源融合特征进行统一整合与关系建模，输出用于最终检测预测的候选框级特征。

模块级执行流程¶

整个融合流程可概括为以下顺序：

  1. 特征与候选框生成（接口层）
  2. 图像特征由 ImageFeatureExtractorInterface 提供

  3. 点云特征与 3D 候选框由 LiDARDetectorInterface 提供

  4. 全局融合阶段（GlobalFusion）

  5. voxel 几何中心计算
  6. 点云与图像空间对齐

  7. 图像语义注入与候选框特征生成

  8. 局部融合阶段（LocalFusion）

  9. RoI 内部网格划分
  10. 几何位置编码

  11. 网格级跨模态融合

  12. 特征聚合阶段（FeatureAggregation）

  13. 多源特征合并
  14. 网格关系建模与动态聚合
  15. 输出最终检测特征

class LoGoNetFramework(nn.Module):
    """
    LoGoNet 跨模态融合主框架（算子化实现）。

    本框架将 LoGoNet 的整体前向流程封装为一个可调用模块，负责串联：
    1）LiDAR 侧接口模块（点云特征提取 + 3D 候选框生成）
    2）Image 侧接口模块（图像特征提取）
    3）全局融合、局部融合与特征聚合等算子（包含函数算子与可学习层算子）

    其中：
    - **函数形式算子**已通过 `torch.library.custom_op` 注册，调用时统一使用 `torch.ops.logonet.xxx`
    - **层形式算子**以 `nn.Module` 形式组织，可参与训练并具有可学习参数

    Args:
        lidar_detector (LidarDetectorInterface):
            点云侧检测接口模块，用于从点云输入中提取点云特征并生成 3D 候选框（RoIs）。
            该模块是可替换的，便于后续替换为真实 3D Backbone + Proposal 生成器。

        image_extractor (ImageFeatureExtractorInterface):
            图像侧特征提取接口模块，用于从输入图像中提取 2D 特征图。
            该模块是可替换的，便于后续替换为真实 2D Backbone（CNN/Transformer）。

        feat_dim (int):
            框架内部使用的统一特征通道维度，默认 64。
            该维度会同时约束：
            - 点云特征通道数
            - 图像特征通道数
            - 融合特征通道数
            - 聚合模块输入输出通道数
    """
    def __init__(
        self,
        lidar_detector: LidarDetectorInterface,
        image_extractor: ImageFeatureExtractorInterface,
        feat_dim: int = 64,
    ):
        super().__init__()

        self.lidar_detector = lidar_detector
        self.image_extractor = image_extractor

        self.global_fusion = GlobalFusionLayer(
            lidar_channels=feat_dim,
            image_channels=feat_dim,
        )

        self.pos_encoding = PositionEncodingLayer(
            out_channels=feat_dim,
        )

        self.local_fusion = LocalFusionLayer(
            pos_channels=feat_dim,
            image_channels=feat_dim,
            out_channels=feat_dim,
        )

        self.feature_aggregation = FeatureAggregationLayer(
            channels=feat_dim
        )

        self.refine_head = RoIRefineHead(
            in_channels=feat_dim
        )

    def forward(self, batch_dict):
        """
        执行 LoGoNet 完整前向融合流程，并输出用于 3D 检测的分类与回归结果。

        整体逻辑按融合顺序分为四段：
        1）Interface：获取点云特征、RoIs、图像特征
        2）Global Fusion：场景级跨模态融合 + RoI 汇聚
        3）Local Fusion：RoI 内部网格级融合（细粒度）
        4）Feature Aggregation：多源特征合并、关系建模与输出预测

        Args:
            batch_dict (dict):
                输入字典，至少需要包含以下字段（由 demo 或数据加载器提供）：

                points (torch.Tensor):
                    点云坐标张量，shape 通常为 **(N, 3)**。
                    - N：点数
                    - 3：xyz 坐标（LiDAR 坐标系）
                    注意：本框架的函数算子会使用该坐标进行投影与 RoI 筛选。

                images (torch.Tensor):
                    图像张量，shape 为 **(B, 3, H, W)**。
                    - B：batch size
                    - H/W：原始图像大小
                    Image 接口模块将其转换为 2D 特征图 `image_features`。

                camera_intrinsic (torch.Tensor):
                    相机内参矩阵，shape 为 **(3, 3)**。
                    用于将三维点投影到二维图像平面。

                camera_extrinsic (torch.Tensor):
                    相机外参矩阵，shape 为 **(4, 4)**。
                    用于将 LiDAR 坐标系点转换到相机坐标系。

                roi_batch_indices (torch.Tensor, optional):
                    RoI 对应的 batch 索引，shape 为 **(K, )**。
                    demo 单 batch 情况下可省略，默认会构造全 0。

        Returns:
            dict:
                cls_score (torch.Tensor):
                    候选框分类得分，shape 为 **(K, num_classes)**。
                    - K：候选框数量（RoIs 数量）
                    num_classes 由检测头实现决定（Simple 通常为 1）。

                reg_offset (torch.Tensor):
                    候选框回归输出，shape 为 **(K, box_dim)**。
                    box_dim 通常为 7，对应 (x, y, z, dx, dy, dz, yaw) 的回归量或偏移量。

                rois (torch.Tensor):
                    3D 候选框张量，shape 为 **(K, 7)**，格式：
                    (x, y, z, dx, dy, dz, yaw)。
                    该输出用于定位每个候选框，并作为后续融合与 refine 的几何依据。

        关键中间变量说明：
            lidar_features:
                点云侧提取的特征表示（由 lidar_detector 输出）。
            image_features:
                图像侧特征图（由 image_extractor 输出）。
            voxel_centroids:
                通过 compute_voxel_centroid 得到的点云几何中心，用于与图像建立对应关系。
            points_2d:
                三维点投影到图像后的二维坐标，用于在图像特征图中采样对应语义信息。
            global_feat:
                全局融合后的特征表示（场景级注入图像语义）。
            roi_feat:
                RoI 特征池化结果（将场景特征按 RoI 汇聚）。
            roi_grids:
                RoI 内部网格坐标（用于细粒度局部融合）。
            pos_feat:
                网格位置编码特征（提供几何结构先验）。
            local_feat:
                RoI 网格级融合特征（对齐图像局部语义）。
            fused_feat:
                合并全局/局部/几何信息后的统一融合表示。
            aggregated_feat:
                通过 FeatureAggregationLayer 建模网格间关系后的最终特征。
        """
        # ---------------- Interface ----------------
        batch_dict = self.lidar_detector(batch_dict)
        batch_dict = self.image_extractor(batch_dict)

        lidar_features = batch_dict["lidar_features"]
        rois = batch_dict["rois"]
        image_features = batch_dict["image_features"]

        # ---------------- GlobalFusion ----------------
        voxel_centroids = torch.ops.logonet.compute_voxel_centroid(
            batch_dict["points"].unsqueeze(1),
            torch.ones(
                batch_dict["points"].shape[0],
                device=batch_dict["points"].device
            )
        )

        points_2d = torch.ops.logonet.project_points_to_image(
            voxel_centroids,
            batch_dict["camera_intrinsic"],
            batch_dict["camera_extrinsic"],
        )

        global_feat = self.global_fusion(
            lidar_features,
            image_features,
            points_2d,
        )

        roi_feat = torch.ops.logonet.roi_feature_pooling(
            global_feat,
            batch_dict["points"],  # 作为 voxel_coords / point_coords
            rois,
        )

        # ---------------- LocalFusion ----------------
        roi_grids = torch.ops.logonet.generate_roi_grids(rois,4)

        # fake demo 用：用 rois 的中心作为 roi_centers
        roi_centers = rois[:, 0:3]  # (K, 3)

        # fake demo 用：每个 grid 的点数，直接全 1
        grid_point_counts = torch.ones(
            roi_grids.shape[0],
            roi_grids.shape[1],
            device=roi_grids.device
        )

        pos_feat = self.pos_encoding(
            roi_grids,
            roi_centers,
            grid_point_counts
        )

        grid_2d = torch.ops.logonet.project_grid_centers_to_image(
            roi_grids,
            batch_dict["camera_intrinsic"],
            batch_dict["camera_extrinsic"],
        )

        local_feat = self.local_fusion(
            pos_feat,
            image_features,
            grid_2d,
            batch_dict.get(
                "roi_batch_indices",
                torch.zeros(rois.shape[0], dtype=torch.long)
            ),
        )

        # ---------------- FeatureAggregation ----------------
        fused_feat = torch.ops.logonet.merge_fusion_features(
            roi_feat,
            local_feat,
            pos_feat,
        )

        aggregated_feat = self.feature_aggregation(fused_feat)

        cls_score, reg_offset = self.refine_head(aggregated_feat)

        return {
            "cls_score": cls_score,
            "reg_offset": reg_offset,
            "rois": rois,
        }

            三维点投影到图像后的二维坐标，用于在图像特征图中采样对应语义信息。
        global_feat:
            全局融合后的特征表示（场景级注入图像语义）。
        roi_feat:
            RoI 特征池化结果（将场景特征按 RoI 汇聚）。
        roi_grids:
            RoI 内部网格坐标（用于细粒度局部融合）。
        pos_feat:
            网格位置编码特征（提供几何结构先验）。
        local_feat:
            RoI 网格级融合特征（对齐图像局部语义）。
        fused_feat:
            合并全局/局部/几何信息后的统一融合表示。
        aggregated_feat:
            通过 FeatureAggregationLayer 建模网格间关系后的最终特征。
    """
    # ---------------- Interface ----------------
    batch_dict = self.lidar_detector(batch_dict)
    batch_dict = self.image_extractor(batch_dict)

    lidar_features = batch_dict["lidar_features"]
    rois = batch_dict["rois"]
    image_features = batch_dict["image_features"]

    # ---------------- GlobalFusion ----------------
    voxel_centroids = torch.ops.logonet.compute_voxel_centroid(
        batch_dict["points"].unsqueeze(1),
        torch.ones(
            batch_dict["points"].shape[0],
            device=batch_dict["points"].device
        )
    )

    points_2d = torch.ops.logonet.project_points_to_image(
        voxel_centroids,
        batch_dict["camera_intrinsic"],
        batch_dict["camera_extrinsic"],
    )

    global_feat = self.global_fusion(
        lidar_features,
        image_features,
        points_2d,
    )

    roi_feat = torch.ops.logonet.roi_feature_pooling(
        global_feat,
        batch_dict["points"],  # 作为 voxel_coords / point_coords
        rois,
    )

    # ---------------- LocalFusion ----------------
    roi_grids = torch.ops.logonet.generate_roi_grids(rois,4)

    # fake demo 用：用 rois 的中心作为 roi_centers
    roi_centers = rois[:, 0:3]  # (K, 3)

    # fake demo 用：每个 grid 的点数，直接全 1
    grid_point_counts = torch.ones(
        roi_grids.shape[0],
        roi_grids.shape[1],
        device=roi_grids.device
    )

    pos_feat = self.pos_encoding(
        roi_grids,
        roi_centers,
        grid_point_counts
    )

    grid_2d = torch.ops.logonet.project_grid_centers_to_image(
        roi_grids,
        batch_dict["camera_intrinsic"],
        batch_dict["camera_extrinsic"],
    )

    local_feat = self.local_fusion(
        pos_feat,
        image_features,
        grid_2d,
        batch_dict.get(
            "roi_batch_indices",
            torch.zeros(rois.shape[0], dtype=torch.long)
        ),
    )

    # ---------------- FeatureAggregation ----------------
    fused_feat = torch.ops.logonet.merge_fusion_features(
        roi_feat,
        local_feat,
        pos_feat,
    )

    aggregated_feat = self.feature_aggregation(fused_feat)

    cls_score, reg_offset = self.refine_head(aggregated_feat)

    return {
        "cls_score": cls_score,
        "reg_offset": reg_offset,
        "rois": rois,
    }
